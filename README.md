# Calculadora de Sistemas Lineares

Projeto desenvolvido para a disciplina de Matemática Aplicada, utilizando HTML, CSS e JavaScript.

## 1. Aplicação

O projeto é uma calculadora que resolve sistemas lineares com duas incógnitas (X e Y).

O usuário pode preencher os valores das duas equações, escolher os sinais e clicar no botão para ver o resultado.

**Link do site: https://muriloasl21.github.io/Fast-Calculation/

## 2. Problema escolhido

O exemplo utilizado é de um fazendeiro chamado Daniel, que vende arroz por R$ 10,00 o quilo e feijão por R$ 5,00 o quilo.

Em um dia, ele vendeu 10 kg dos dois produtos e recebeu R$ 80,00. O objetivo é descobrir quanto ele vendeu de cada produto.

O sistema utilizado foi:

- x + y = 10
- 10x + 5y = 80

Nesse caso, X representa o arroz e Y representa o feijão.

## 3. Prompt utilizado na IA

"Crie uma calculadora de sistemas lineares utilizando HTML, CSS e JavaScript. Quero que seja possível alterar os coeficientes e os sinais das equações, calcular os valores de X e Y e mostrar a resolução passo a passo. Adicione um exemplo prático explicado acima da calculadora."

Depois da primeira versão, pedi para melhorar a organização do site, separar melhor os textos e organizar os botões e campos da calculadora.

## 4. Verificação do resultado

Utilizei o exemplo do fazendeiro Daniel para testar a calculadora.

Resolvendo manualmente:

x + y = 10

10x + 5y = 80

O resultado encontrado foi:

- X = 6 kg de arroz.
- Y = 4 kg de feijão.

A calculadora apresentou os mesmos valores, confirmando o resultado.
